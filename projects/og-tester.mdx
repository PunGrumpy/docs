## Surfaces

| Surface | Purpose |
| --- | --- |
| Scan report | What the crawlers will actually see for a given URL |
| Recommendations | What is missing or malformed, and what to set instead |
| CLI | The same check, runnable in a pipeline |

## The failure it addresses

Social metadata fails silently. Nothing in a build breaks when `og:image` points at a 404, and the first
signal is usually a link shared in public that renders as a grey rectangle. Validation has to happen
before the share, which is why the CLI matters more than the web form: a check that only exists as a
website is a check that runs after the mistake.
