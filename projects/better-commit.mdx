| --- | --- |

| Agent support | The same convention applies to AI tools writing commits |
| Hooks and CI | Enforcement at commit time and in the pipeline |
| Documentation | Setup and configuration reference on the project site |

## Why a config file and not a convention document

Commit conventions fail in a specific way. The rule is written in a contributing guide, half enforced by
a commit-msg hook someone copied in 2023, and quietly ignored by every tool that generates commits
automatically. Once agents are writing commits too, the gap widens: the convention lives in prose that
the agent may or may not have read.

Better Commit collapses that into a single artefact. The config is the convention, the CLI reads it, the
hook enforces it, and CI checks it. Agents get the same input as humans because there is only one input.
