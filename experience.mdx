## Open source maintainer and independent developer

**November 2023 to present.** Maintains cloud-native applications and developer tooling in Go and
TypeScript. The published output is visible: [Logixlysia](https://www.pungrumpy.com/showcase/logixlysia) has been maintained
across three years and now carries its own documentation site, and the 2026 tooling run added four
independent CLIs and web tools.

Maintenance here means the unglamorous half as well: release automation, migration guides, issue triage,
and the documentation rewrites that keep a plugin usable after its API grows.

## Platform engineer intern, IBM Thailand

**June to December 2025.** Designed deployment workflows on GitHub Actions, OpenShift, and IBM Cloud,
with the work concentrated on authentication and observability. The same engagement produced
[Thai Seatizen](https://www.pungrumpy.com/showcase/thai-seatizen), a gamified marine-education platform powered by AI.

## Community ambassador, FOSSASIA

**January to March 2025.** Selected as the representative for Thailand at FOSSASIA Summit 2025.
